# Kymyz - Kyrgyz Heritage Website

A modern, ethno-contemporary website showcasing Kyrgyz cultural heritage through storytelling, featuring a minimalist design with smooth animations and responsive layout.

## 🌟 Features

- **Full-Size Hero Section**: Stunning background images with scroll-triggered animations
- **Dark Navigation & Footer**: Modern dark theme with high contrast
- **Beautiful Card Design**: Glass-morphism effects with hover animations
- **Responsive Layout**: Optimized for all screen sizes
- **Smooth Animations**: Framer Motion powered transitions
- **Modern UI/UX**: Clean, minimalist design with attention to detail

## 🛠️ Technology Stack

- **Frontend**: React 18
- **Build Tool**: Vite
- **Styling**: CSS3 with modern features
- **Animations**: Framer Motion
- **Routing**: React Router DOM
- **Icons**: Lucide React

## 🚀 Getting Started

### Prerequisites

- Node.js (v14 or higher)
- npm or yarn

### Installation

1. Clone the repository:
```bash
git clone https://github.com/AidanaUsup/website1.git
cd website1
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm run dev
```

4. Open your browser and navigate to `http://localhost:5173`

### Build for Production

```bash
npm run build
```

### Preview Production Build

```bash
npm run preview
```
